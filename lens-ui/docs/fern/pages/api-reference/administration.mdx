## Backend API

Administration spans the auth router in `llm_d_bench/auth/router.py` and the system-settings router in `llm_d_bench/db/system_router.py`.

Auth and administration routes live under the `/api/v1` prefix from `llm_d_bench/auth/router.py`.

### List users

List users, including direct roles, group memberships, and inherited roles.

<Tabs>
  <Tab title="REST API">

**`GET /api/v1/users`**

Request:

- Query params:
  - `query` (`string`, optional): filter by username or other user-search text.
  - `status` (`string`, optional): filter by user status such as `active` or `disabled`.

This endpoint has no request body.

Response:

Returns an array of user records enriched with direct `roles`, `groups`, and `inheritedRoles`.

```json
[
  {
    "username": "alice",
    "display_name": "Alice Admin",
    "id": "user-1",
    "email": "alice@example.com",
    "provider_id": null,
    "auth_source": "local",
    "external_id": null,
    "status": "active",
    "failed_login_count": 0,
    "locked_until": null,
    "must_change_password": false,
    "password_changed_at": "2026-09-21T08:00:00+00:00",
    "last_login_at": "2026-09-23T08:45:00+00:00",
    "principal_version": 3,
    "created_at": "2026-09-20T10:00:00+00:00",
    "updated_at": "2026-09-23T08:45:00+00:00",
    "has_password": true,
    "protected": false,
    "roles": [
      {
        "name": "maintainer",
        "scopeType": "cluster",
        "scopeClusterId": "cluster-123"
      }
    ],
    "groups": [
      {
        "id": "group-ops",
        "name": "ops",
        "source": "manual"
      }
    ],
    "inheritedRoles": [
      {
        "name": "end-user",
        "scopeType": "global",
        "scopeClusterId": null,
        "scopeResourceType": null,
        "scopeResourceId": null,
        "groupId": "group-ops",
        "groupName": "ops"
      }
    ]
  }
]
```

  </Tab>
  <Tab title="Python API">

```python
from llm_d_bench.auth.service import default_service

service = default_service()
role_names = {role.id: role.name for role in service.role_dao.list()}
group_names = {group.id: group.name for group in service.group_dao.list()}
user_bindings = service.user_binding_dao.list_all()
group_bindings = service.group_binding_dao.list_all()
memberships = service.user_group_dao.list_all()
users = service.user_dao.list(query="alice", status="active")

print(len(users), len(user_bindings), len(group_bindings), len(memberships))
print(role_names)
print(group_names)
```

### Create a user

Create a user account.

<Tabs>
  <Tab title="REST API">

**`POST /api/v1/users`**

Request:

- JSON body fields:
  - `username` (`string`, required)
  - `password` (`string`, optional)
  - `displayName` (`string`, optional)
  - `email` (`string`, optional)

```json
{
  "username": "alice",
  "password": "<strong-password>",
  "displayName": "Alice Admin",
  "email": "alice@example.com"
}
```

Response:

Returns the created user record from `_user_public(...)`.

```json
{
  "username": "alice",
  "display_name": "Alice Admin",
  "id": "user-1",
  "email": "alice@example.com",
  "provider_id": null,
  "auth_source": "local",
  "external_id": null,
  "status": "active",
  "failed_login_count": 0,
  "locked_until": null,
  "must_change_password": false,
  "password_changed_at": null,
  "last_login_at": null,
  "principal_version": 1,
  "created_at": "2026-09-23T09:00:00+00:00",
  "updated_at": "2026-09-23T09:00:00+00:00",

  "protected": false
}
```

  </Tab>
  <Tab title="Python API">

```python
from llm_d_bench.auth.service import default_service
```

**`PATCH /api/v1/users/{user_id}`**

Request:

- Path params:
  - `user_id` (`string`, required): the user record to update.

  - `displayName` (`string`, optional)

```json
  "email": "alice.ops@example.com",
  "status": "active"
}
```

Response:

Returns the updated user record.

```json
{
  "username": "alice",
  "display_name": "Alice Operations",
  "id": "user-1",
  "email": "alice.ops@example.com",
  "provider_id": null,
  "auth_source": "local",
  "external_id": null,
  "status": "active",
  "failed_login_count": 0,
  "locked_until": null,
  "must_change_password": false,
  "password_changed_at": null,
  "last_login_at": "2026-09-23T08:45:00+00:00",
  "principal_version": 2,
  "created_at": "2026-09-20T10:00:00+00:00",
  "updated_at": "2026-09-23T09:05:00+00:00",
  "has_password": true,
  "protected": false
}
```

  </Tab>
  <Tab title="Python API">

```python
from llm_d_bench.auth.router import UserUpdateRequest
```

- Path params:

```json
    "cluster:cluster:read",
```

### List sessions

List sessions; admins can include revoked sessions, while other callers see their own sessions.

<Tabs>
  <Tab title="REST API">

**`GET /api/v1/sessions`**

Request:

- Query params:
  - `include_revoked` (`boolean`, optional): admins can include revoked sessions in the result set.

This endpoint has no request body.

Response:

Returns a list of session records. Admin callers receive every session plus a `username` field; non-admin callers receive only their own sessions.

```json
[
  {
    "user_id": "user-1",
    "token_hash": "$argon2id$v=19$m=65536,t=3,p=4$sessionhash",
    "id": "session-1",
    "created_at": "2026-09-23T08:45:00+00:00",
    "expires_at": "2026-09-23T16:45:00+00:00",
    "idle_expires_at": "2026-09-23T10:45:00+00:00",
    "last_seen_at": "2026-09-23T09:15:00+00:00",
    "revoked_at": null,
    "auth_source": "local",
    "ip": "127.0.0.1",
    "user_agent": "Mozilla/5.0",
    "username": "alice"
  }
]
```

  </Tab>
  <Tab title="Python API">

```python
from llm_d_bench.auth.service import default_service

service = default_service()
admin_view = service.session_dao.list_all(include_revoked=True)
self_view = service.list_sessions("user-1")

print(len(admin_view), len(self_view))
```

  </Tab>
</Tabs>

### Grant cluster access

Grant cluster-scoped access to a user or group.

<Tabs>
  <Tab title="REST API">

**`POST /api/v1/clusters/{cluster_id}/access`**

Request:

- Path params:
  - `cluster_id` (`string`, required): the authoritative cluster scope for the binding.
- JSON body fields:
  - `subjectType` (`"user" | "group"`, required)
  - `subjectId` (`string`, required)
  - `roleId` (`string`, required)
  - `clusterId` (`string`, optional): present in the request model, but the route uses the `{cluster_id}` path parameter as the scope.

```json
{
  "subjectType": "user",
  "subjectId": "user-1",
  "roleId": "role-maintainer"
}
```

Response:

Returns the created binding record.

```json
{
  "user_id": "user-1",
  "role_id": "role-maintainer",
  "id": "binding-user-1",
  "scope_type": "cluster",
  "scope_cluster_id": "cluster-123",
  "scope_resource_type": null,
  "scope_resource_id": null,
  "granted_by_user_id": "admin-1",
  "expires_at": null,
  "created_at": "2026-09-23T09:20:00+00:00"
}
```

  </Tab>
  <Tab title="Python API">

```python
from llm_d_bench.auth.service import default_service

binding = default_service().add_user_binding(
    "user-1",
    "role-maintainer",
    scope_type="cluster",
    scope_cluster_id="cluster-123",
    granted_by="admin-1",
)
print(binding.id, binding.scope_cluster_id)
```

### Revoke cluster access

Revoke a cluster-scoped access binding.

<Tabs>
  <Tab title="REST API">

**`DELETE /api/v1/clusters/{cluster_id}/access/{binding_id}`**

Request:

- Path params:
  - `cluster_id` (`string`, required): the cluster whose binding is being removed.
  - `binding_id` (`string`, required): the user or group binding id to revoke.

This endpoint has no request body.

Response:

Returns `204 No Content` after the binding is removed. This endpoint does not return a JSON body.

  </Tab>
  <Tab title="Python API">

```python
from llm_d_bench.auth.service import default_service

service = default_service()
for binding in service.user_binding_dao.list_all():
    if binding.id == "binding-user-1":
        service.remove_user_binding(binding.user_id, binding.id)
        break
else:
    for binding in service.group_binding_dao.list_all():
        if binding.id == "binding-group-1":
            service.remove_group_binding(binding.group_id, binding.id)
            break

print("binding revoked")
```

  </Tab>
</Tabs>

### Configure the backend database

Configure Prism's own database connection (external or embedded) and create the initial tables.

<Tabs>
  <Tab title="REST API">

**`POST /api/v1/system/database`**

Request:

- JSON body fields:
  - `mode` (`"external" | "embedded"`, required)
  - `engine` (`"postgresql" | "mysql" | "oracle" | "mssql"`, optional)
  - `databaseUrl` (`string`, required for `external` mode)
  - `embeddedPassword` (`string`, optional; only meaningful for `embedded` mode)

External-database example:

```json
{
  "mode": "external",
  "engine": "mysql",
  "databaseUrl": "mysql://prism:secret@db.example.com:3306/prism"
}
```

Response:

Returns the resulting `DatabaseStatus` after connection probing, engine configuration, and initial table creation succeed.

```json
{
  "configured": true,
  "mode": "external",
  "engine": "mysql",
  "displayTarget": "db.example.com:3306/prism"
}
```

  </Tab>
  <Tab title="Python API">

```python
from llm_d_bench.db.system_router import DatabaseSetupRequest, apply_database_setup

status = apply_database_setup(
    DatabaseSetupRequest(
        mode="external",
        engine="mysql",
        databaseUrl="mysql://prism:secret@db.example.com:3306/prism",
    )
)
print(status.configured, status.mode, status.engine)
```

### Read the stored-secret master key status

Read the effective master key (`LENS_SECRET_KEY`) source, a non-reversible fingerprint, and how many provider secrets and old fallback keys exist. The key value itself is never returned.

<Tabs>
  <Tab title="REST API">

**`GET /api/v1/system/secret-key`**

Request:

This endpoint has no request body.

Response:

```json
{
  "source": "file",
  "envLocked": false,
  "configured": true,
  "fingerprint": "3f9a1c7b52e0d4a6",
  "keyLength": 64,
  "oldKeyCount": 1,
  "path": "/home/user/.local/share/lens/credentials/master_key.json",
  "providerSecretCount": 2
}
```

`source` is `environment`, `file`, or `unconfigured`; `envLocked` is `true` when `LENS_SECRET_KEY` is supplied through the environment (the stored key is then ignored and rotation through the API is rejected).

  </Tab>
  <Tab title="Python API">

```python
from llm_d_bench.auth.master_key import status
from llm_d_bench.auth.settings import get_settings

print(status(get_settings())["source"], status(get_settings())["fingerprint"])
```

  </Tab>
</Tabs>

### Rotate the stored-secret master key

Generate a new master key (or use a supplied one), re-encrypt every stored provider secret with it, and retain the previous key(s) as decryption fallback. Rejected when `LENS_SECRET_KEY` is environment-locked.

<Tabs>
  <Tab title="REST API">

**`POST /api/v1/system/secret-key/rotate`**

Request:

- JSON body fields:
  - `newKey` (`string`, optional; leave empty to auto-generate a strong key)

```json
{
  "newKey": "a-manually-chosen-strong-key"
}
```

Response:

Returns the new status plus `rotatedSecrets`, the number of provider secrets re-encrypted.

```json
{
  "source": "file",
  "envLocked": false,
  "configured": true,
  "fingerprint": "b71e0c9d3a4f8215",
  "keyLength": 28,
  "oldKeyCount": 1,
  "path": "/home/user/.local/share/lens/credentials/master_key.json",
  "providerSecretCount": 2,
  "rotatedSecrets": 2
}
```

  </Tab>
  <Tab title="Python API">

```python
from llm_d_bench.auth.master_key import rotate_master_key
from llm_d_bench.auth.settings import get_settings
from llm_d_bench.db.dao.identity_provider import IdentityProviderDao

result = rotate_master_key(get_settings(), None, provider_dao=IdentityProviderDao())
print(result["fingerprint"], result["rotatedSecrets"])
```

  </Tab>
</Tabs>

### Clear previous master keys

Drop the retained fallback keys once every provider secret has been re-encrypted. Secrets still encrypted with an old key become unreadable, so re-save those providers first.

<Tabs>
  <Tab title="REST API">

**`DELETE /api/v1/system/secret-key/old`**

Request:

This endpoint has no request body.

Response:

Returns the status with `oldKeyCount` set to `0`.

  </Tab>
  <Tab title="Python API">

```python
from llm_d_bench.auth.master_key import clear_old_keys
from llm_d_bench.auth.settings import get_settings

print(clear_old_keys(get_settings())["oldKeyCount"])
```

  </Tab>
</Tabs>
