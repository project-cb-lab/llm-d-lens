## Backend API

Model Service routes are split across `llm_d_bench/model_service/router.py`'s user, admin, public, and internal routers.

### List model access tokens

List the caller's active model access tokens. The response never includes plaintext token values, only the metadata needed to identify and revoke them later.

<Tabs>
  <Tab title="REST API">
    **`GET /api/v1/model-service/tokens`**

    Request: no request body. The caller must be authenticated with a Prism user session.

    Response: returns an `items` array of `ModelAccessToken` records projected through `ModelAccessToken.api_payload()`, so `tokenHash` is omitted.

    ```json
    {
      "items": [
        {
          "id": "mat-7f2c4a19b6d1",
          "userId": "user-123",
          "name": "laptop",
          "tokenHint": "9mQx",
          "status": "active",
          "lastUsedAt": "2026-09-23T08:15:00Z",
          "lastUsedIp": "10.0.0.25",
          "createdAt": "2026-09-21T12:00:00Z"
        }
      ]
    }
    ```
  </Tab>
  <Tab title="Python API">
    ```python
    from llm_d_bench.model_service.service import default_service

    service = default_service()
    tokens = service.tokens.list_for_user("user-123", include_revoked=False)
    for token in tokens:
        print(token.api_payload())
    ```
  </Tab>
</Tabs>

### Create a model access token

Create a new model access token for the caller. The plaintext token is returned exactly once together with the persisted token metadata.

<Tabs>
  <Tab title="REST API">
    **`POST /api/v1/model-service/tokens`**

    Request body (`TokenCreateRequest`):

    - `name` (`string`): display name for the token.

    ```json
    {
      "name": "automation"
    }
    ```

    Response: one `ModelAccessToken` payload plus the one-time `token` string.

    ```json
    {
      "id": "mat-2c47de48a35b",
      "userId": "user-123",
      "name": "automation",
      "tokenHint": "K8xP",
      "status": "active",
      "createdAt": "2026-09-23T09:00:00Z",
      "token": "lens-mk-bTj9X7mW4zP1qN8sR6uC2yF5hL0aV3dK1mQ"
    }
    ```
  </Tab>
  <Tab title="Python API">
    ```python
    from llm_d_bench.model_service.service import default_service

    service = default_service()
    token, raw_token = service.tokens.create("user-123", name="automation")

    print(token.api_payload())
    print(raw_token)
    ```
  </Tab>
</Tabs>

### Regenerate a model access token

Revoke the caller's current active token or tokens, then issue a fresh token. You can optionally give the replacement token a name.

<Tabs>
  <Tab title="REST API">
    **`POST /api/v1/model-service/tokens/regenerate`**

    Request body: optional `TokenCreateRequest`. If omitted, the route uses `"default"`.

    ```json
    {
      "name": "default"
    }
    ```

    Response: the newly issued token metadata plus the new plaintext token.

    ```json
    {
      "id": "mat-54b2a51d9d93",
      "userId": "user-123",
      "name": "default",
      "tokenHint": "F6rN",
      "status": "active",
      "createdAt": "2026-09-23T09:05:00Z",
      "token": "lens-mk-Gq4nP1sT8uV2xY5zA7bC9dE3fH6jK8mN0pR"
    }
    ```
  </Tab>
  <Tab title="Python API">
    ```python
    from llm_d_bench.model_service.service import default_service

    service = default_service()
    token, raw_token = service.tokens.regenerate("user-123", name="default")

    print(token.id, raw_token)
    ```
  </Tab>
</Tabs>

### Revoke a model access token

Revoke one previously issued model access token for the caller. After revocation, the token can no longer be used for gateway access.

<Tabs>
  <Tab title="REST API">
    **`DELETE /api/v1/model-service/tokens/{token_id}`**

    Request: no request body.

    - `token_id` (`string`, path): token id such as `mat-7f2c4a19b6d1`.

    Response: `204 No Content`. This endpoint does not return a JSON body.
  </Tab>
  <Tab title="Python API">
    ```python
    from llm_d_bench.model_service.service import default_service

    service = default_service()
    revoked = service.tokens.revoke("user-123", "mat-7f2c4a19b6d1")
    print(revoked)
    ```
  </Tab>
</Tabs>

### List accessible models

List the model groups that the caller is currently allowed to use through the model gateway. Only active groups with at least one authorized active member are returned. Each entry includes `clusterName` (resolved from the group's `clusterId`) so callers choosing between several model services -- for example the same public name published in different clusters -- can tell them apart without a separate cluster lookup.

<Tabs>
  <Tab title="REST API">
    **`GET /api/v1/model-service/models`**

    Request: no request body. The caller must be authenticated with a Prism user session.

    Response: returns an `items` array of `ModelServiceGroup` payloads, each with an added `clusterName`.

    ```json
    {
      "items": [
        {
          "id": "msg-4a8b41f3dd6c",
          "name": "qwen3-8b",
          "modelRef": "Qwen/Qwen3-8B",
          "displayName": "Qwen3 8B",
          "description": "Shared Qwen 3 8B service",
          "selectionPolicy": "random",
          "status": "active",
          "clusterId": "cluster-a",
          "clusterName": "Cluster A",
          "servedName": "Qwen/Qwen3-8B",
          "baseModel": "Qwen/Qwen3-8B",
          "createdByUserId": "user-123",
          "createdAt": "2026-09-20T15:00:00Z",
          "updatedAt": "2026-09-22T11:30:00Z"
        }
      ]
    }
    ```
  </Tab>
  <Tab title="Python API">
    ```python
    from llm_d_bench.model_service.service import default_service

    service = default_service()
    entries = service.list_model_entries_for_user("user-123")
    for entry in entries:
        print(entry["name"], entry["clusterName"])
    ```
  </Tab>
</Tabs>

### Get gateway connection info

Return the Gateway connection info a client copies into its OpenAI client. Each cluster runs its own Gateway, so the response lists one connection per cluster the caller can access; `LENS_MODEL_GATEWAY_PUBLIC_URL`, when set, is a single override applied to every cluster.

<Tabs>
  <Tab title="REST API">
    **`GET /api/v1/model-service/connection`**

    Request: no request body.

    Response: the global override (empty string when unset) plus a per-cluster list.

    ```json
    {
      "baseUrl": "",
      "clusters": [
        {
          "clusterId": "cluster-a",
          "clusterName": "Cluster A",
          "provider": "istio",
          "gatewayName": "lens-inference-gateway",
          "address": "10.0.0.10",
          "baseUrl": "http://10.0.0.10/v1",
          "ready": true
        }
      ]
    }
    ```
  </Tab>
  <Tab title="Python API">
    ```python
    import os

    import asyncio

    from llm_d_bench.model_service.gateway_ops import GatewayOpsService

    global_url = os.environ.get("LENS_MODEL_GATEWAY_PUBLIC_URL", "").strip()
    status = asyncio.run(GatewayOpsService().status())
    clusters = [
        {
            "clusterId": cluster.cluster_id,
            "clusterName": cluster.cluster_name,
            "provider": cluster.gateway_provider,
            "address": cluster.gateway_address,
            "baseUrl": global_url or (f"http://{cluster.gateway_address}/v1" if cluster.gateway_address else ""),
        }
        for cluster in status.clusters
    ]

    print({"baseUrl": global_url, "clusters": clusters})
    ```
  </Tab>
</Tabs>

### List OpenAI-compatible models

Return an OpenAI-style `GET /v1/models` response for a valid model token. The model list is filtered to the groups visible to that token's owning user.

<Tabs>
  <Tab title="REST API">
    **`GET /v1/models`**

    Request: no request body. Pass the model token with either `Authorization: Bearer <token>` or `x-api-key: <token>`.

    Response: standard OpenAI-compatible model-list payload.

    ```json
    {
      "object": "list",
      "data": [
        {
          "id": "qwen3-8b",
          "object": "model",
          "created": 1727107200,
          "owned_by": "lens"
        }
      ]
    }
    ```
  </Tab>
  <Tab title="Python API">
    ```python
    from llm_d_bench.model_service.service import default_service

    service = default_service()
    record = service.tokens.validate("lens-mk-bTj9X7mW4zP1qN8sR6uC2yF5hL0aV3dK1mQ", ip="10.0.0.25")
    if record is None:
        raise RuntimeError("token is missing, expired, or revoked")

    payload = {
        "object": "list",
        "data": [
            {
                "id": group.name,
                "object": "model",
                "created": int(group.created_at.timestamp()),
                "owned_by": "lens",
            }
            for group in service.list_models_for_user(record.user_id)
        ],
    }
    print(payload)
    ```
  </Tab>
</Tabs>

### List usage records

List the caller's recent usage records, with simple paging through `limit` and `offset`. Each item is the stored `UsageRecord` projected with its camelCase API aliases. The llm-d EPP reports only input/output tokens, so `cachedInputTokens` is currently always `0` (the field is kept for engines that expose it).

<Tabs>
  <Tab title="REST API">
    **`GET /api/v1/model-service/usage/records`**

    Request: no request body.

    - `limit` (`integer`, query, default `100`, max `500`): number of records to return.
    - `offset` (`integer`, query, default `0`): zero-based offset into the caller's ledger.

    Response: an `items` array of usage records.

    ```json
    {
      "items": [
        {
          "id": "usg-8c2d9e1fa410",
          "requestId": "req-20260923-0001",
          "userId": "user-123",
          "tokenId": "mat-2c47de48a35b",
          "groupId": "msg-4a8b41f3dd6c",
          "groupName": "qwen3-8b",
          "clusterId": "cluster-a",
          "executionId": "exec-qwen3-8b",
          "modelRef": "Qwen/Qwen3-8B",
          "provider": "vllm",
          "inputTokens": 512,
          "cachedInputTokens": 128,
          "cacheWriteTokens": 0,
          "outputTokens": 196,
          "usageSource": "engine",
          "status": "success",
          "streaming": false,
          "ttftMs": 240,
          "durationMs": 1310,
          "createdAt": "2026-09-23T08:40:00Z"
        }
      ]
    }
    ```
  </Tab>
  <Tab title="Python API">
    ```python
    from llm_d_bench.model_service.service import default_service

    service = default_service()
    records = service.usage.list_for_user("user-123", limit=100, offset=0)
    for record in records:
        print(record.api_payload())
    ```
  </Tab>
</Tabs>

### Get daily usage totals

Aggregate the caller's recent usage records into daily token totals. The handler reuses the same usage ledger and buckets it with `_daily_totals`.

<Tabs>
  <Tab title="REST API">
    **`GET /api/v1/model-service/usage/timeseries`**

    Request: no request body.

    - `days` (`integer`, query, default `30`, range `1..365`): number of recent days to include.

    Response: daily usage buckets with totals for each token class.

    ```json
    {
      "items": [
        {
          "date": "2026-09-22",
          "requests": 4,
          "inputTokens": 1200,
          "cachedInputTokens": 300,
          "cacheWriteTokens": 0,
          "outputTokens": 640
        },
        {
          "date": "2026-09-23",
          "requests": 2,
          "inputTokens": 530,
          "cachedInputTokens": 64,
          "cacheWriteTokens": 0,
          "outputTokens": 211
        }
      ]
    }
    ```
  </Tab>
  <Tab title="Python API">
    ```python
    from datetime import datetime, timedelta

    from llm_d_bench.model_service.router import _daily_totals
    from llm_d_bench.model_service.service import default_service

    service = default_service()
    since = datetime.now() - timedelta(days=30)
    records = service.usage.list_for_user("user-123", since=since, limit=10000)
    print(_daily_totals(records))
    ```
  </Tab>
</Tabs>

### Create a model routing group

Create a routing group that exposes one user-facing model name in a single cluster. `name` and `clusterId` are required; the public name is unique per cluster (`clusterId`) and every provider must be a deployment in that same cluster. Lens derives `modelRef`/`baseModel` from `name` and `displayName` defaults to `name`.

<Tabs>
  <Tab title="REST API">
    **`POST /api/v1/model-service/admin/groups`**

    Request body (`GroupCreateRequest`):

    - `name` (`string`): the model name clients use (also the routing/model ref).
    - `clusterId` (`string`): the cluster the service belongs to (required); its providers must be in this cluster and the name is unique within it.
    - `displayName` (`string`, optional): UI-friendly label; defaults to `name`.
    - `description` (`string`, optional): free-form description.
    - `modelRef` / `servedName` / `baseModel` (`string`, optional, advanced): derived from `name` when omitted.
    - `selectionPolicy` (`string`, legacy): accepted for compatibility; the llm-d data plane ignores it.

    ```json
    {
      "name": "qwen3-8b",
      "modelRef": "Qwen/Qwen3-8B",
      "clusterId": "cluster-a",
      "servedName": "Qwen/Qwen3-8B",
      "baseModel": "Qwen/Qwen3-8B",
      "displayName": "Qwen3 8B",
      "description": "Shared Qwen 3 8B service"
    }
    ```

    Response: the created `ModelServiceGroup`.

    ```json
    {
      "id": "msg-4a8b41f3dd6c",
      "name": "qwen3-8b",
      "modelRef": "Qwen/Qwen3-8B",
      "clusterId": "cluster-a",
      "servedName": "Qwen/Qwen3-8B",
      "baseModel": "Qwen/Qwen3-8B",
      "displayName": "Qwen3 8B",
      "description": "Shared Qwen 3 8B service",
      "selectionPolicy": "random",
      "status": "active",
      "createdByUserId": "user-123",
      "createdAt": "2026-09-23T09:10:00Z",
      "updatedAt": "2026-09-23T09:10:00Z"
    }
    ```
  </Tab>
  <Tab title="Python API">
    ```python
    from llm_d_bench.model_service.contracts import GroupCreateRequest
    from llm_d_bench.model_service.service import default_service

    service = default_service()
    group = service.create_group(
        GroupCreateRequest(
            name="qwen3-8b",
            modelRef="Qwen/Qwen3-8B",
            clusterId="cluster-a",
            servedName="Qwen/Qwen3-8B",
            baseModel="Qwen/Qwen3-8B",
            displayName="Qwen3 8B",
            description="Shared Qwen 3 8B service",
        ),
        created_by="user-123",
    )
    print(group.api_payload())
    ```
  </Tab>
</Tabs>

### List published model service members

    ```json
          "id": "msm-32d55cb7f9a1",
          "groupId": "msg-4a8b41f3dd6c",
          "executionId": "exec-qwen3-8b",
          "clusterId": "cluster-a",

          "targetService": "vllm",

          "endpointKind": "vllm",
          "status": "active",
          "publishedByUserId": "user-123",
          "createdAt": "2026-09-23T09:12:00Z",
          "updatedAt": "2026-09-23T09:12:00Z",
          "name": "qwen-qwen3-8b-202609210558"
        }
      ]
    }
    ```
  </Tab>
  <Tab title="Python API">
    ```python
    from llm_d_bench.model_service.service import default_service
    ```

### Publish a deployment as a member

<Tabs>
  <Tab title="REST API">
    **`POST /api/v1/model-service/admin/members`**

    Request body (`MemberCreateRequest`):

    - `groupId` (`string`): target routing group id.
    - `executionId` (`string`): ready deployment execution id.
    - `poolName` (`string`, optional, advanced): the deployment-owned InferencePool name; defaults to the deployment's pool stored as `namespace/pool` (unique across namespaces).

    ```json
    {
      "groupId": "msg-4a8b41f3dd6c",
      "executionId": "exec-qwen3-8b",
      "poolName": "ns/qwen"
    ```

    Response: the created `ModelServiceMember`.

    ```json
      "executionId": "exec-qwen3-8b",
      "clusterId": "cluster-a",
      "targetNamespace": "ns",
      "targetService": "qwen-epp",
      "targetPort": 8000,
      "endpointKind": "llm-d-epp",
      "poolName": "qwen",
      "eppRef": "qwen-epp",
      "status": "active",
      "ownerUserId": "user-123",
      "publishedByUserId": "user-123",
      "createdAt": "2026-09-23T09:12:00Z",
    ```

### Stream a data-plane operation

Run a data-plane operation and stream its log lines as Server-Sent Events. Used by the admin UI for install/uninstall/reconcile so the log drawer updates live.

<Tabs>
  <Tab title="REST API">
    **`POST /api/v1/model-service/admin/gateway/stream`**

    Request body (`GatewayStreamRequest`):

    - `clusterId` (`string`)
    - `op` (`string`): `install-gateway` | `uninstall-gateway` | `reconcile` | `scale` | `install-ipp` | `uninstall-ipp`
    - `provider`, `namespace`, `name`, `replicas`, `kind`, `gatewayName`, `ippChart`, `ippVersion` (optional, depending on `op`)

    ```json
    { "clusterId": "cluster-a", "op": "reconcile" }
    ```

    Response: `text/event-stream`; each event carries one log line, then the terminal `GatewayOperation` payload.
  </Tab>
  <Tab title="Python API">
    The stream is an HTTP transport; the equivalent Python calls run the operation directly.

    ```python
    import asyncio

    from llm_d_bench.model_service.gateway_ops import GatewayOpsService

    async def main() -> None:
        ops = GatewayOpsService()
        await ops.reconcile_cluster_gateway("cluster-a")          # op=reconcile
        await ops.install_cluster_gateway("cluster-a")            # op=install-gateway
        await ops.uninstall_inference_gateway("cluster-a")        # op=uninstall-gateway
        await ops.install_ipp("cluster-a")                        # op=install-ipp
        await ops.uninstall_ipp("cluster-a")                      # op=uninstall-ipp

    asyncio.run(main())
    ```
  </Tab>
</Tabs>

### Stream a component's logs

Stream live logs (`kubectl logs -f`) for a data-plane component. Used by the admin data-plane diagram to watch Gateway / IPP / EPP output in real time.

<Tabs>
  <Tab title="REST API">
    **`POST /api/v1/model-service/admin/gateway/logs`**

    Request body (`ComponentLogsRequest`):
    - `clusterId` (`string`): target cluster.
    - `component` (`string`, optional): `gateway` or `ipp` — the backend resolves the namespace/name.
    - `namespace` / `name` (`string`, optional): explicit coordinates when no `component` is given.
    - `kind` (`string`, default `deployment`), `container` (`string`, optional), `tail` (`integer`, default `200`).

    ```json
    { "clusterId": "cluster-a", "component": "gateway" }
    ```

    Response: `text/event-stream`; each `log` event carries one line, then a terminal `complete`.
  </Tab>
  <Tab title="Python API">
    ```python
    import asyncio

    from llm_d_bench.model_service.gateway_ops import GatewayOpsService

    async def main() -> None:
        namespace, name = await GatewayOpsService().resolve_log_target(
            "cluster-a", component="gateway", namespace=None, name=None
        )
        async for line in GatewayOpsService().stream_component_logs("cluster-a", namespace, name, tail=50):
            print(line)

    asyncio.run(main())
    ```
