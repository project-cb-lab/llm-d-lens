## Backend API

Local and Pod execution share request progress reporting through `llm_d_bench.simulation.progress.report_request_progress`. Pod reporting still waits for readiness; local reporting retains its original start time. Backend adapters share artifact error formatting through `backends.analytics.artifact_error_message`, while retaining their own error/timeout field precedence, status mapping, and metric units. Task APIs and backend environment preparation are unchanged.

Simulation routes live in `llm_d_bench/simulation/router.py` under the `/api/simulation` prefix.

### Discover endpoint models

Probe a model endpoint and discover which models it reports.

<Tabs>
  <Tab title="REST API">
    **`POST /api/simulation/models/discover`**

    Request body: `ModelDiscoveryRequest`
    - `endpoint_url` (`string`, required)

    ```json
    {
      "endpoint_url": "http://127.0.0.1:38000/v1"
    }
    ```

    Response:

    ```json
    {
      "endpoint": "http://127.0.0.1:38000/v1",

        "Qwen/Qwen3-8B",
        "Qwen/Qwen3-8B-Instruct"
    ```

```python
import asyncio

from llm_d_bench.simulation.endpoints import discover_models


async def main() -> None:
```

### Create a simulation task

Create a Simulation task that replays a trace dataset against a target model endpoint.

<Tabs>
  <Tab title="REST API">
    **`POST /api/simulation/tasks`**

    Request body: `SimulationTaskCreateRequest`
    - `name`, `description`, `scenario`, `backend`, `endpoint_mode`
    - `cluster_session_id`, `endpoint_namespace`, `endpoint_service`, `endpoint_deployment_execution_id`, `endpoint_cluster_id`, `endpoint_cluster_name`, `endpoint_deployment_name`
    - `model_service_group_id` (`string`, optional) — target a published, continuously health-probed
      Model Service instead of a raw deployment execution. When set, the backend resolves it to the
      group's active member and published name and forces `endpoint_mode` to `"deployment"`,
      overriding any supplied `endpoint_deployment_execution_id`/`model_name`. Requires `api_key`.
    - `api_key` (`string`, optional) — model access token; required when `model_service_group_id` is set.
    - `endpoint_url`, `model_name`, `trace_dataset`, `trace_path`
    - `duration_seconds`, `scale_factor`, `trace_start_seconds`, `trace_end_seconds`, `trace_timeout_seconds`, `fixed_schedule`, `stream`, `backend_options`

### Download a simulation artifact

Download a saved simulation artifact by task id and artifact kind as a file attachment.

<Tabs>
  <Tab title="REST API">
    **`GET /api/simulation/tasks/{task_id}/artifacts/{kind}`**

    Request: no body.
    - Path parameters: `task_id` (`string`, required), `kind` (`string`, required)

    Response: file attachment streamed from the saved artifact path. No JSON body is returned. The task's `result.artifacts` list tells you which `kind` values are available.
  </Tab>
  <Tab title="Python API">

```python
import asyncio

from llm_d_bench.simulation.router import download_simulation_artifact


async def main() -> None:
    response = await download_simulation_artifact("1a2b3c4d", "summary-json")
```
