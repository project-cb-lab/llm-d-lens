## Backend API

Download, deletion and incremental node synchronization share `launch_cache_jobs` in `llm_d_bench.model_cache.jobs`. Public service calls below retain their existing signatures: callers select nodes and prepare credentials, while the launcher initializes progress and submits Jobs. Incremental synchronization preserves existing nodes; partial submission failures propagate without marking the whole batch in progress.


Routes live in `llm_d_bench/model_cache/router.py`. Each endpoint below documents the REST contract and the matching `ModelCacheService` or Hugging Face helper call it uses.

Deployments consume the cache directly. `llm_d_bench.deploy.providers.model_cache_environment.model_cache_environment` runs every cache-backed model server with Hugging Face offline (`HF_HUB_OFFLINE=1`, `TRANSFORMERS_OFFLINE=1`), and adds `HF_HOME=/model-cache` for the `auto-cache` source so vLLM resolves the model from the mounted snapshot instead of contacting `huggingface.co` at startup. Providers that mount the model directory directly (`shared-path`, `mountPath`, including P/D disaggregation, precise-prefix-cache-routing and tiered-prefix-cache) get the offline flags without `HF_HOME`. This keeps cache-backed startup working on restricted or flaky networks (for example `repo_utils.py` SSL `unexpected_eof_while_reading` failures). The `huggingface` source still downloads at startup and stays online.

Hugging Face environment variables (`HF_*`, `HUGGING*`, `TRANSFORMERS_*`) are administrator-managed. The deployment planning API and configuration validation reject user-supplied `customParameters` entries that set them (see `llm_d_bench/configuration/managed_environment.py`), and the deployment editor blocks them with an "administrator-managed" message. The platform injects these values from the cluster's saved proxy, model cache and token configuration.

### List Model Cache entries

List Model Cache entries, optionally filtered by cluster or storage volume. Use this to discover cached model ids, download state, and node sync drift.

<Tabs>
  <Tab title="REST API">
    **`GET /api/v1/model-cache/entries`**

    Request: no request body. Optional query params: `cluster_id` (`str`) and `storage_volume_id` (`str`).

    Response: returns an `items` array of Model Cache entries, with each item including the router-computed `pendingSyncNodes` field.

    ```json
    {
      "items": [
        {
          "id": "model-cache-7f3a2c1d",
          "clusterId": "cluster-123",
          "storageVolumeId": "storage-abc12345",
          "source": {
            "kind": "huggingface",
            "huggingface": {
              "repoId": "Qwen/Qwen2.5-7B-Instruct",
              "revision": "main"
            }
          },
          "tokenSource": {
            "mode": "none",
            "namespace": null,
            "name": null
          },
          "status": "ready",
          "cachePath": "hub/models--Qwen--Qwen2.5-7B-Instruct",
          "sizeBytes": 15123042304,
          "nodeProgress": [
            {
              "node": "worker-1",
              "status": "ready",
              "failureDetail": null
            }
          ],
          "failureDetail": null,
          "createdAt": "2026-09-23T08:15:00Z",
          "updatedAt": "2026-09-23T08:22:11Z",
          "pendingSyncNodes": ["worker-2"]
        }
      ]
    }
    ```
  </Tab>
  <Tab title="Python API">
    ```python
    import asyncio

    from llm_d_bench.model_cache.service import default_service


    async def main() -> None:
        service = default_service()
        entries = await service.list(cluster_id="cluster-123", storage_volume_id=None)
        pending = await service.compute_pending_sync(entries)
        payload = [
            {**entry.api_payload(), "pendingSyncNodes": pending.get(entry.id, [])}
            for entry in entries
        ]
        print(payload)


    asyncio.run(main())
    ```
  </Tab>
</Tabs>

### Get a Model Cache entry

Get one Model Cache entry by id, including source, token mode, node progress, and pending sync nodes.

<Tabs>
  <Tab title="REST API">
    **`GET /api/v1/model-cache/entries/{entry_id}`**

    Request: no request body. Path param: `entry_id` (`str`).

    Response: returns one Model Cache entry object plus the router-computed `pendingSyncNodes` list.

    ```json
    {
      "id": "model-cache-7f3a2c1d",
      "clusterId": "cluster-123",
      "storageVolumeId": "storage-abc12345",

          "repoId": "Qwen/Qwen2.5-7B-Instruct",
          "revision": "main"
        }
      },
      "tokenSource": {
        "mode": "existing-secret",
        "namespace": "models",
        "name": "hf-token"
      },
      "status": "downloading",
      "cachePath": "hub/models--Qwen--Qwen2.5-7B-Instruct",
      "sizeBytes": null,
      "nodeProgress": [
        {
          "node": "worker-1",
          "status": "downloading",
          "failureDetail": null
        },
        {
          "node": "worker-2",
          "status": "pending",
          "failureDetail": null
        }
      ],
      "failureDetail": null,
      "createdAt": "2026-09-23T08:15:00Z",
      "updatedAt": "2026-09-23T08:16:09Z",
    ```

### Request a model download

Request a model download into Lens Model Cache. Use this to seed a ready shared model cache before deployments or benchmarks.

<Tabs>
  <Tab title="REST API">
    **`POST /api/v1/model-cache/entries`**

    Request: body fields are `clusterId` (`str`), `storageVolumeId` (`str`), and `source` (`ModelSource`). `tokenSource` is accepted for compatibility but ignored: downloads always use the HuggingFace token saved with the cluster (the wizard's `hf_token_secret`), or run unauthenticated when the cluster has none.

    ```json
    {
      "clusterId": "cluster-123",
      "storageVolumeId": "storage-abc12345",
      "source": {
        "kind": "huggingface",
        "huggingface": {
          "repoId": "Qwen/Qwen2.5-7B-Instruct",
          "revision": "main"
        }
      },
      "tokenSource": {
        "mode": "existing-secret",
        "namespace": "models",
        "name": "hf-token"
      }
    }
    ```

    Response: returns the queued `ModelCacheEntry` payload that was created for the download request.

    ```json
    {
      "id": "model-cache-7f3a2c1d",
      "clusterId": "cluster-123",
      "storageVolumeId": "storage-abc12345",
      "source": {
        "kind": "huggingface",
        "huggingface": {
          "repoId": "Qwen/Qwen2.5-7B-Instruct",
          "revision": "main"
        }
      },
      "tokenSource": {
        "mode": "existing-secret",
        "namespace": "models",
        "name": "hf-token"
      },
      "status": "pending",
      "cachePath": "hub/models--Qwen--Qwen2.5-7B-Instruct",
      "sizeBytes": null,
      "nodeProgress": [],
      "failureDetail": null,
      "createdAt": "2026-09-23T08:15:00Z",
      "updatedAt": "2026-09-23T08:15:00Z",
      "pendingSyncNodes": []
    }
    ```
  </Tab>
  <Tab title="Python API">
    ```python
    import asyncio

    from llm_d_bench.model_cache.contracts import HuggingFaceSource, ModelCacheCreateRequest, ModelSource, ModelSourceKind, TokenSource, TokenSourceMode
    from llm_d_bench.model_cache.service import default_service


    async def main() -> None:
        service = default_service()
        entry = await service.request_download(
            ModelCacheCreateRequest(
                clusterId="cluster-123",
                storageVolumeId="storage-abc12345",
                source=ModelSource(
                    kind=ModelSourceKind.HUGGINGFACE,
                    huggingface=HuggingFaceSource(repoId="Qwen/Qwen2.5-7B-Instruct", revision="main"),
                ),
                tokenSource=TokenSource(mode=TokenSourceMode.EXISTING_SECRET, namespace="models", name="hf-token"),
            )
        )
        await service.provision(entry.id)
        print(entry.id, entry.status)


    asyncio.run(main())
    ```
  </Tab>
</Tabs>

### Sync new nodes for all entries

Trigger sync for all local-disk Model Cache entries that are missing on newly added nodes. Optionally scope the work to one cluster.

<Tabs>
  <Tab title="REST API">
    **`POST /api/v1/model-cache/entries/sync-nodes`**

    Request: no request body. Optional query param: `cluster_id` (`str`).

    Response: returns the entries that were changed and queued for new-node provisioning.

    ```json
    {
      "items": [
        {
          "id": "model-cache-7f3a2c1d",
          "clusterId": "cluster-123",
          "storageVolumeId": "storage-abc12345",
          "source": {
            "kind": "huggingface",
            "huggingface": {
              "repoId": "Qwen/Qwen2.5-7B-Instruct",
              "revision": "main"
            }
          },
          "tokenSource": {
            "mode": "none",
            "namespace": null,
            "name": null
          },
          "status": "downloading",
          "cachePath": "hub/models--Qwen--Qwen2.5-7B-Instruct",
          "sizeBytes": 15123042304,
          "nodeProgress": [
            {
              "node": "worker-1",
              "status": "ready",
              "failureDetail": null
            },
            {
              "node": "worker-2",
              "status": "pending",
              "failureDetail": null
            }
          ],
          "failureDetail": null,
          "createdAt": "2026-09-23T08:15:00Z",
          "updatedAt": "2026-09-23T08:35:00Z",
          "pendingSyncNodes": []
        }
      ]
    }
    ```
  </Tab>
  <Tab title="Python API">
    ```python
    import asyncio

    from llm_d_bench.model_cache.service import default_service


    async def main() -> None:
        service = default_service()

        print([entry.id for entry in changed])


    asyncio.run(main())
    ```

### Delete a Model Cache entry

Delete a Model Cache entry and, when required, schedule cleanup of its downloaded files. Set `keep_files=true` to remove the record only.

<Tabs>
  <Tab title="REST API">
    **`DELETE /api/v1/model-cache/entries/{entry_id}`**

    Request: no request body. Path param: `entry_id` (`str`). Optional query param: `keep_files` (`bool`, default `false`).

    Response: usually returns the entry in `deleting` state while background cleanup runs. If the entry never reached a persisted cache path, the API may instead return a minimal `{"id": ..., "status": "deleted"}` acknowledgement.

    ```json
    {
      "id": "model-cache-7f3a2c1d",
      "clusterId": "cluster-123",
      "storageVolumeId": "storage-abc12345",
      "source": {
        "kind": "huggingface",
        "huggingface": {
          "repoId": "Qwen/Qwen2.5-7B-Instruct",
          "revision": "main"
        }
      },
      "tokenSource": {
        "mode": "none",
        "namespace": null,
        "name": null
      },
      "status": "deleting",
      "cachePath": "hub/models--Qwen--Qwen2.5-7B-Instruct",
      "sizeBytes": 15123042304,
      "nodeProgress": [
        {
          "node": "worker-1",
          "status": "ready",
          "failureDetail": null
        }
      ],
      "failureDetail": null,
      "createdAt": "2026-09-23T08:15:00Z",
      "updatedAt": "2026-09-23T09:00:00Z",
      "pendingSyncNodes": []
    }
    ```
  </Tab>
  <Tab title="Python API">
    ```python
    import asyncio

    from llm_d_bench.model_cache.service import default_service


    async def main() -> None:
        service = default_service()
        entry = await service.request_delete("model-cache-7f3a2c1d", keep_files=False)
        if entry is not None:
            await service.provision_delete(entry.id)
            print(entry.api_payload())
        else:
            print({"id": "model-cache-7f3a2c1d", "status": "deleted"})


    asyncio.run(main())
    ```
  </Tab>
</Tabs>

### Get Model Cache logs

Get logs for one Model Cache entry, optionally scoped to a specific node. Use this to debug download or cleanup failures.

<Tabs>
  <Tab title="REST API">
    **`GET /api/v1/model-cache/entries/{entry_id}/logs`**

    Request: no request body. Path param: `entry_id` (`str`). Optional query param: `node` (`str`).

    Response: returns the collected log text for the entry, or for the requested node only.

    ```json
    {
      "logs": "[worker-1] pulling Qwen/Qwen2.5-7B-Instruct@main\n[worker-1] download completed successfully"
    }
    ```
  </Tab>
  <Tab title="Python API">
    ```python
    import asyncio

    from llm_d_bench.model_cache.service import default_service


    async def main() -> None:
        service = default_service()
        logs = await service.get_logs("model-cache-7f3a2c1d", node="worker-1")
        print(logs)


    asyncio.run(main())
    ```
  </Tab>
</Tabs>

### Search Hugging Face models

Search Hugging Face model repositories from Lens Model Cache. Use this to discover repo ids before creating a cache entry.

<Tabs>
  <Tab title="REST API">
    **`GET /api/v1/model-cache/huggingface/search`**

    Request: no request body. Query params: `query` (`str`) and optional `limit` (`int`, default `20`).

    Response: returns Hugging Face search matches as `HuggingFaceModelSummary` objects.

    ```json
    {
      "items": [
        {
          "repoId": "Qwen/Qwen2.5-7B-Instruct",
          "likes": 12345,
          "downloads": 987654,
          "pipelineTag": "text-generation",
          "tags": ["transformers", "text-generation", "safetensors"],
          "lastModified": "2026-09-01T12:00:00.000Z",
          "gated": false
        }
      ]
    }
    ```
  </Tab>
  <Tab title="Python API">
    ```python
    import asyncio

    from llm_d_bench.model_cache import huggingface_hub


    async def main() -> None:
        items = await huggingface_hub.search_models("Qwen2.5", limit=5)
        summaries = [item["id"] for item in items]
        print(summaries)


    asyncio.run(main())
    ```
  </Tab>
</Tabs>

### Get Hugging Face model details

Get detailed Hugging Face metadata for one model repository, including the README snapshot Lens fetched.

<Tabs>
  <Tab title="REST API">
    **`GET /api/v1/model-cache/huggingface/models/{repo_id:path}`**

    Request: no request body. Path param: `repo_id` (`str`, for example `Qwen/Qwen2.5-7B-Instruct`).

    Response: returns a `HuggingFaceModelDetail` object.

    ```json
    {
      "repoId": "Qwen/Qwen2.5-7B-Instruct",
      "likes": 12345,
      "downloads": 987654,
      "pipelineTag": "text-generation",
      "tags": ["transformers", "text-generation", "safetensors"],
      "lastModified": "2026-09-01T12:00:00.000Z",
      "gated": false,
      "readme": "---\nlibrary_name: transformers\n---\n# Qwen2.5-7B-Instruct"
    }
    ```
  </Tab>
  <Tab title="Python API">
    ```python
    import asyncio

    from llm_d_bench.model_cache import huggingface_hub


    async def main() -> None:
        detail = await huggingface_hub.get_model_detail("Qwen/Qwen2.5-7B-Instruct")
    ```
