## Backend API

Model Market does **not** have a dedicated backend module. Its catalog is static frontend data in `src/data/modelCatalog.js`, so there is no backend catalog API to document. The page only calls shared cluster and deployment APIs.

### List Lens-managed clusters

List Lens-managed clusters, optionally including draft records that have not yet been finalized.

<Tabs>
  <Tab title="REST API">

**`GET /api/cluster/clusters`**

Request:

- Query params:
  - `includeDrafts` (`boolean`, optional): include draft cluster records that have not been finalized yet.

This endpoint has no request body.

Response:

Returns a `ClustersResponse` object with an `items` array of `ClusterRecord` objects.

```json
{
  "items": [
    {
      "id": "cluster-123",
      "name": "lab-cluster",
      "description": "Shared Intel GPU cluster",
      "createdAt": "2026-09-20T10:15:00+00:00",
      "ready": true,
      "proxy": {
        "mode": "auto",
        "httpProxy": null,
        "httpsProxy": null,
        "noProxy": null
      },
      "llmDRef": "v0.9.0",
      "llmDBenchmarkRef": "main",
      "llmDRepoPath": "/opt/prism/checkouts/llm-d",
      "llmDBenchmarkRepoPath": "/opt/prism/checkouts/llm-d-benchmark",
      "deploymentSource": {
        "resolved_from": "cluster-registry",
        "ref": "v0.9.0"
      },
      "benchmarkSource": {
        "resolved_from": "cluster-registry",
        "ref": "main"
      },
      "draft": false
    }
  ]
}
```

  </Tab>
  <Tab title="Python API">

```python
import asyncio

from llm_d_bench.cluster import service


async def main() -> None:
    clusters = service.list_clusters(include_drafts=True)
    readiness = await asyncio.gather(*(service.cluster_is_ready(cluster) for cluster in clusters))

    for cluster, is_ready in zip(clusters, readiness):
        print(cluster.id, cluster.name, is_ready)


asyncio.run(main())
```

### Start a Standard Kubernetes Service deployment run

Start a Standard Kubernetes Service deployment run using Lens's allowlisted vLLM contract.

<Tabs>
  <Tab title="REST API">

**`POST /api/v1/deployments/standard-vllm-runs`**

Request:

- JSON body fields:
  - `model` (`string`, required)
  - `deployment_name` (`string`, required)
  - `description` (`string`, optional)
  - `cluster_session_id` (`string`, required, 36 chars)
  - `replicas` (`integer`, required)
  - `tensor_parallel_size` (`integer`, required)
  - `storage_type` (`"local-cache" | "pvc" | "model-cache"`, optional)
  - `storage_volume_id` (`string`, optional)
  - `model_cache_path` (`string`, optional)
  - `pvc_name` (`string`, optional)
  - `max_model_len` (`integer`, optional)
  - `gpu_memory_utilization` (`number`, optional)
  - `max_num_seqs` (`integer`, optional)
  - `max_num_batched_tokens` (`integer`, optional)
  - `enable_prefix_caching` (`boolean`, optional)
  - `enforce_eager` (`boolean`, optional)
  - `vllm_arguments` (`array<object>`, optional; each item uses `name` and `value` string keys)
  - `use_cluster_proxy` (`boolean`, optional)
  - `http_proxy` (`string`, optional)
  - `https_proxy` (`string`, optional)
  - `no_proxy` (`string`, optional)

```python
import asyncio

from llm_d_bench.deploy.application import deployment_run_manager
from llm_d_bench.deploy.contracts import DeploymentRunCreateRequest
from llm_d_bench.deploy.standard_kubernetes_service import (
    StandardKubernetesServiceRequest,
    build_standard_kubernetes_service_configuration,
)


async def main() -> None:
    request = StandardKubernetesServiceRequest(
        model="Qwen/Qwen3-8B",
        deployment_name="qwen3-8b-standard",
        description="Model Market launch",
        cluster_session_id="123e4567-e89b-12d3-a456-426614174000",
        replicas=2,
        tensor_parallel_size=2,
        storage_type="local-cache",
        model_cache_path="/home/prism/.cache",
        max_model_len=8192,
        gpu_memory_utilization=0.85,
        max_num_seqs=128,
        max_num_batched_tokens=4096,
        enable_prefix_caching=True,
        vllm_arguments=[{"name": "enable-auto-tool-choice", "value": "true"}],
        use_cluster_proxy=True,
        http_proxy="http://proxy.example:911",
        https_proxy="http://proxy.example:911",
        no_proxy="localhost,.svc",
    )
    configuration = build_standard_kubernetes_service_configuration(request)
    run = await deployment_run_manager.start_run(
        DeploymentRunCreateRequest(
            configurations=[configuration],
            provenance={
                "deployment_source": {"kind": "standard-kubernetes-service"},
                "cluster_session_id": request.cluster_session_id,
                "deployment_name": request.deployment_name,
                "description": request.description.strip(),
                "model_market": {
                    "deployment_name": request.deployment_name,
                    "description": request.description.strip(),
                },
            },
        )
    )
    print(run.id, run.status)


asyncio.run(main())
```
