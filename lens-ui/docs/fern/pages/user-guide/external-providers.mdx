---
title: External providers
description: Configure OpenAI-compatible AI providers used by agentic features.
---

Use the External providers page to manage the OpenAI- or Anthropic-compatible endpoints used by Prism's optional AI features. The steps below are based on the controls that exist in the current page and modals.

Provider connections require a public HTTPS base URL. Paths such as `/openai/v1.0` are supported; credentials, query strings, fragments, and private network destinations are rejected when testing or calling a provider. A provider can still be saved without a successful connection test.

Provider refreshes keep the existing rows while loading. A superseded request cannot replace newer results; a failed refresh retains the previous list. The delete confirmation disables repeated submission and dismissal while deletion is pending, and displays failures for retry.

## Add a provider

1. On **External providers**, click **Add provider**.
2. In **Add AI provider**, fill in **Name**, **API type**, **Base URL**, **Model**, **API key**, and **Timeout (seconds)**.
3. If you want to verify the draft before saving, click **Test connection**. The page notes this is **Optional — you can save even if this fails.**
4. When the form looks correct, click **Add provider**.

## Search and filter providers

1. Use **Search name, base URL, or model...** to filter the table.
2. Open **Type** to filter by provider type.
3. Click **Clear Filters** to remove the active filters.
4. Review the filtered results in the **External providers** table.

## Test a saved provider

1. Find the provider in the **External providers** table.
2. In the **Test** column, click **Test**.
3. Wait for the status icon to update in the same row, then hover it if you need the full result message.

## Edit a provider

1. In the provider row, click the action whose aria-label is **Edit _provider name_**.
2. In **Edit AI provider**, update the fields you need.
3. If the **API key** line says the key is already saved, leave the field blank when you want to keep the existing key.
4. Optionally click **Test connection** to check the edited settings.
5. Click **Save changes**.

## Delete a provider

1. In the provider row, click the action whose aria-label is **Delete _provider name_**.
2. In **Delete AI provider**, review the warning text.
3. Click **Delete provider**.
