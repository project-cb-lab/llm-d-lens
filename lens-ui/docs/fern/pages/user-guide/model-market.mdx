---
title: Model Market
description: Browse the model catalog and start a one-click deployment.
---

The Model Market page helps you choose a catalog model and hand it off to deployment. It is a frontend catalog backed by the UI's built-in model list, then a guided deployment form.

## Browse models by category

1. Open **Model Market**.
2. In the **Model categories** row, click a category such as **All**, **Text**, **Vision**, **Speech**, **Encoder**, or **Rerank** to filter the grid.
3. Review each model card's built-in fields: **Released**, **Precision**, **Weights**, **Context**, and **Model type**.
4. Click the model card you want to use to open **One-click deployment**.

## Create a standard deployment

1. From **One-click deployment**, confirm the selected model, then fill in **Deployment name**.
2. Optional: enter **Description**.
3. In **Cluster**, choose a ready cluster. If you need to switch back to the catalog first, click **Model Market** in the header.
4. In **Model cache storage**, pick a storage volume. If you do not have one yet, click **Manage storage**.
5. Wait until the page shows **This model is ready in the selected cache.** If it shows **This model is not downloaded in the selected storage. Clear it or download the model there first.**, fix the cache first.
6. Leave **Mode** on **Standard**.
7. Optional: expand **vLLM parameters** and adjust fields such as **GPU memory utilization**, **Max model length**, **Max number of sequences**, **Max batched tokens**, **Prefix caching**, **Enforce eager execution**, or **Custom vLLM parameters**.
8. Optional: expand **Deployment environment** and change **Use cluster proxy**, **HTTP proxy**, **HTTPS proxy**, or **NO_PROXY**.
9. Review **Standard vLLM plan**.
10. Click **Create deployment**, then confirm with **Confirm & deploy** if the resource-basis chooser appears.
11. After the request succeeds, Lens opens [Deployments](/user-guide/deployments).

## Hand off to the advanced deployment workflow

1. Open a model from **Model Market** so the **One-click deployment** form appears.
2. Fill in **Deployment name**, choose a **Cluster**, and set **Model cache storage** if you want to reuse cached weights.
3. In **Mode**, click **Advanced**.
4. Click **Configure deployment**.
5. Continue in the deployment configuration flow that opens next.

## Start the agentic deployment planner

1. Open a model from **Model Market**.
2. Fill in the basic form fields you already know, such as **Deployment name**, **Cluster**, and **Model cache storage**.
3. In **Mode**, click **Agentic**.
4. Continue in the embedded planner that opens below the form.

## Permissions

If the page shows **Your role cannot create deployments.**, you can still click **Open Deployments** to view existing deployments, but you cannot submit **One-click deployment** from this page.
