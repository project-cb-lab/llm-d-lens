---
title: Node BFF
description: Node/Express gateway routes exposed to the browser.
---

The Node BFF is the same-origin gateway the browser calls. It authenticates
requests, re-signs them for the Python API, and serves a small number of
Node-native endpoints. Every route is under `/api`. Domain routes are proxied to
the Python API, which is documented in the generated [Python API reference](/api)
section.

## Node-native endpoints

| Method | Path | Purpose |
| --- | --- | --- |
| GET | `/api/config` | Runtime configuration consumed by the frontend. |
| GET | `/api/mcp` | MCP server metadata. |
| POST | `/api/mcp` | MCP JSON-RPC requests from the assistant. |
| DELETE | `/api/mcp` | Close an MCP session. |
| POST | `/api/candidate-support` | Report whether candidate search is available. |
| POST | `/api/candidate-search` | Run the OptimalBench candidate search. |
| POST | `/api/configurations/:operation` | Validate, resolve, render or save configuration artifacts. |
| GET | `/api/guide-planning/catalog` | Guide catalog used for deployment planning. |
| POST | `/api/guide-planning/prepare` | Prepare guide planning inputs. |
| POST | `/api/guide-planning/plan` | Produce a deployment plan. |
| GET | `/api/deploy-poc/config` | Known-good deploy POC configuration. |
| POST | `/api/deploy-poc/start` | Start a deploy POC run. |
| GET | `/api/deploy-poc/status` | Poll deploy POC status. |
| GET | `/api/deploy-poc/validate` | Validate the deploy POC environment. |
| POST | `/api/deploy-poc/teardown` | Tear down the deploy POC. |
| GET | `/api/remote-deploy/defaults` | Default values for remote deployment. |
| POST | `/api/remote-deploy/fingerprint` | Fingerprint a remote host. |
| POST | `/api/remote-deploy/test` | Test connectivity to a remote host. |
| POST | `/api/remote-deploy/start` | Start a remote deployment. |
| POST | `/api/remote-deploy/status` | Poll remote deployment status. |
| POST | `/api/remote-deploy/logs` | Read remote deployment logs. |
| POST | `/api/remote-deploy/teardown` | Tear down a remote deployment. |
| POST | `/api/playground/chat` | Assistant chat endpoint. |
| ANY | `/api/v1/monitoring/*` | Proxy to the monitoring backend. |

## Proxied prefixes

The BFF forwards these prefixes to the Python API (`llm_d_bench`); the two
legacy aliases `/api/cluster` and `/api/simulation` are canonicalized to the
corresponding `/api/v1/...` module paths.

| Prefix | Domain |
| --- | --- |
| `/api/simulation`, `/api/v1/simulation` | Simulation tasks and trace datasets. |
| `/api/cluster`, `/api/v1/cluster`, `/api/cluster-overview`, `/api/v1/clusters` | Cluster discovery and management. |
| `/api/agentic-deployments` | Agentic deployment planning. |
| `/api/v1/configurations` | Configuration artifacts. |
| `/api/v1/deployments`, `/api/v1/executions` | Deployments and executions. |
| `/api/v1/evaluate` | Evaluation runs and workflows. |
| `/api/v1/storage` | Storage volumes and classes. |
| `/api/v1/model-cache` | Model cache entries. |
| `/api/v1/ai-providers` | External AI providers. |
| `/api/v1/aic` | AIC support, search and estimates. |
| `/api/v1/system` | System/database endpoints. |
| `/api/v1/auth`, `/api/v1/users`, `/api/v1/groups`, `/api/v1/roles`, `/api/v1/identity-providers`, `/api/v1/audit-logs`, `/api/v1/sessions` | Authentication and RBAC. |
